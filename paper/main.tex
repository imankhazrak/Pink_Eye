\begin{abstract}
Infectious bovine keratoconjunctivitis (IBK), commonly known as pinkeye,
is a highly contagious ocular disease in cattle that causes significant
welfare and economic losses. Early automated detection from farm images
can enable timely veterinary intervention. We present a two-stage deep
learning pipeline: \emph{Stage~1} localises the eye region using a
YOLOv8 detector, and \emph{Stage~2} classifies the cropped eye as
healthy or diseased using four architectures—ResNet18, EfficientNet-B0,
a baseline CNN+Transformer hybrid, and a proposed enhanced
CNN+Transformer model. Evaluated on a dataset of 394 labelled eye crops
(309 healthy, 85 pink-eye) under stratified 5-fold cross-validation, the
proposed \emph{Strong CNN+Transformer} achieves the highest accuracy
(95.94\,\%), F1-score on the minority pinkeye class (90.51\,\%), and
ROC-AUC (98.50\,\%). Comprehensive ablation studies isolate the
contribution of each augmentation component. Our results demonstrate
that combining convolutional local feature extraction with transformer
global context modelling yields the most robust detector for this
class-imbalanced, fine-grained medical imaging task.
\end{abstract}

\begin{IEEEkeywords}
Pinkeye detection, YOLOv8, CNN+Transformer, class imbalance,
data augmentation, cattle health monitoring, transfer learning.
\end{IEEEkeywords}

\section{Methodology}
\label{sec:methodology}

\subsection{Overview of the Pipeline}
\label{subsec:overview}

The proposed system is a two-stage cascaded pipeline, illustrated in
Fig.~\ref{fig:pipeline}. In the first stage a YOLOv8-based object
detector localises the eye region in each cattle head image. The
detected bounding box is padded and cropped, producing a standardised
eye-region image that forms the input to Stage~2. In the second stage,
four deep classification models are trained and evaluated on the cropped
eye images to discriminate between healthy eyes and eyes affected by IBK.

\begin{figure}[t]
  \centering
  \includegraphics[width=\linewidth]{figures/pipeline_overview.pdf}
  \caption{High-level overview of the two-stage pipeline. Stage~1
    (YOLOv8) localises and crops the eye region; Stage~2
    (classification models) predicts the disease label.}
  \label{fig:pipeline}
\end{figure}

% ----------------------------------------------------------------
\subsection{Dataset}
\label{subsec:dataset}

\subsubsection{Eye Detection Dataset (Stage~1)}
The YOLOv8 detector was trained on 117 cattle head images sourced from
the Roboflow Eye Detection dataset (v3) \cite{roboflow_eye}. Each image
carries a single bounding-box annotation for the \texttt{eye} class in
YOLOv8 normalised format. All 117 annotation files were validated
(correct pairing, well-formed coordinates, class~ID~=~0, no
out-of-range values) prior to training. The dataset was split
deterministically with a fixed random seed (42) into training (80\%,
93 images), validation (10\%, 11 images), and test (10\%, 13 images)
subsets.

\subsubsection{Classification Dataset (Stage~2)}
The full classification dataset comprises 408 cattle head images carrying
disease labels (healthy / pink\_eye). After running YOLOv8 inference and
cropping, 394 images yielded valid eye crops; the remaining 14 produced
no confident detection and were set aside for manual review. The final
classification dataset therefore contains:

\begin{itemize}
  \item \textbf{Healthy (label~0):} 309 images (78.4\,\%)
  \item \textbf{Pink-eye (label~1):} 85 images (21.6\,\%)
\end{itemize}

The class imbalance ratio of approximately 3.64:1 is explicitly handled
by weighted cross-entropy loss and, in ablation experiments, by
minority-only augmentation. All images were resized to
$224 \times 224$ pixels before training.

\subsection{Stage~1: Eye Localisation with YOLOv8}
\label{subsec:stage1}

\subsubsection{Annotation Validation}
Prior to training, the Roboflow annotation set was audited by a custom
validation script that checked image–label pairing, coordinate validity
($x, y, w, h \in [0,1]$), and class identifier correctness. All 117
files passed without errors or warnings.

\subsubsection{Detector Training}
A YOLOv8-nano (YOLOv8n) architecture pretrained on MS-COCO was fine-tuned
on the 93-image training split. Training used the Ultralytics 8.4.21
framework (PyTorch 2.8.0, CUDA 12.8) on a Tesla V100-PCIE 16\,GB GPU.
The full configuration is listed in Table~\ref{tab:yolo_config}.

\subsubsection{Eye Cropping}
After training, the best-checkpoint detector was applied to all 408
classification images using a confidence threshold of 0.25. For each
detected bounding box the crop region was expanded by a 10\,\% symmetric
padding (clamped to image boundaries) before extraction. The resulting
crops represent the localised eye region that serves as input to Stage~2.

\subsection{Stage~2: Classification Models}
\label{subsec:stage2}

\subsubsection{ResNet18 Baseline}
A ResNet18~\cite{he2016resnet} pretrained on ImageNet-1k was adapted for
binary classification by replacing the final fully connected layer with a
$512 \rightarrow 2$ linear head. All backbone weights were fine-tuned
end-to-end.

\subsubsection{EfficientNet-B0 Baseline}
An EfficientNet-B0~\cite{tan2019efficientnet} pretrained on ImageNet-1k
was adapted by replacing its classification head with a $1280 \rightarrow
2$ linear layer. Fine-tuning was performed on all layers.

\subsubsection{Baseline CNN+Transformer Hybrid}
The baseline hybrid model connects a pretrained CNN backbone to a
lightweight Transformer encoder. Feature maps from the final convolutional
stage are projected via a $1 \times 1$ convolution, flattened into a
sequence of patch tokens, and processed by a multi-head self-attention
encoder. Global representation is obtained by mean pooling over all
tokens, followed by a linear classification head. This design couples
CNN local feature extraction with transformer relational reasoning.

\subsubsection{Strong CNN+Transformer (Proposed)}
\label{subsubsec:strong}
The proposed \emph{Strong CNN+Transformer} model is an enhanced version
of the baseline hybrid. Its forward pass is:

\begin{enumerate}
  \item A pretrained EfficientNet-B0 backbone (features-only, last stage
    output) extracts feature maps $\mathbf{F} \in
    \mathbb{R}^{B \times C \times H \times W}$.
  \item A $1 \times 1$ projection followed by BatchNorm and GELU maps
    channels to embedding dimension $d$:
    $\mathbf{F}' \in \mathbb{R}^{B \times d \times H \times W}$.
  \item $\mathbf{F}'$ is flattened to patch tokens
    $\mathbf{T} \in \mathbb{R}^{B \times HW \times d}$.
  \item A learnable CLS token $\mathbf{c} \in \mathbb{R}^d$ is prepended,
    and learnable positional embeddings $\mathbf{P} \in
    \mathbb{R}^{(1+HW) \times d}$ are added:
    \begin{equation}
      \mathbf{T}' = \left[\mathbf{c}; \mathbf{T}\right] + \mathbf{P}.
    \end{equation}
  \item A $L$-layer Transformer encoder (pre-norm formulation,
    multi-head attention with $h$ heads) processes $\mathbf{T}'$.
  \item The CLS token output $\mathbf{z}_0$ is passed through a
    multi-layer MLP head:
    \begin{equation}
      \hat{y} = W_2 \cdot \text{Dropout}\!\left(
        \text{GELU}\!\left(W_1 \cdot \text{LayerNorm}(\mathbf{z}_0)
        \right)\right)
    \end{equation}
    yielding logits over the two classes.
\end{enumerate}

Key architectural hyperparameters are listed in
Table~\ref{tab:strong_config}. CLS-token aggregation provides a dedicated
global representation, learnable positional embeddings preserve spatial
structure, and the deeper MLP head offers additional discriminative
capacity compared with the baseline hybrid.

\subsection{Training Protocol}
\label{subsec:training}

All Stage~2 models were trained and evaluated under the same protocol to
ensure fair comparison.

\subsubsection{Stratified 5-Fold Cross-Validation}
Given the limited size of the dataset (394 images), a stratified 5-fold
cross-validation scheme was adopted. Stratification preserves the
78.4\,\%/21.6\,\% class ratio in every fold. In each iteration, 4 folds
(315--316 images) are used for training and 1 fold (78--79 images) for
validation. Final performance is reported as mean $\pm$ standard deviation
over 5 folds.

\subsubsection{Loss Function and Class Imbalance}
Weighted cross-entropy loss was used throughout. Class weights are
computed as the inverse of class frequency:
\begin{equation}
  w_c = \frac{N}{K \cdot n_c},
\end{equation}
where $N$ is the total number of training samples, $K$ the number of
classes, and $n_c$ the count of class $c$. The resulting weights
($w_0 \approx 0.64$, $w_1 \approx 2.32$) upweight the minority
pink-eye class at every gradient step.

\subsubsection{Optimiser and Scheduler}
The AdamW optimiser~\cite{loshchilov2018adamw} was used with learning
rate $\eta = 10^{-4}$ and weight decay $\lambda = 10^{-4}$.
Early stopping was applied with patience~$= 8$ epochs and minimum
improvement threshold $\delta = 10^{-4}$ on validation F1-score
(pink-eye class). The maximum number of epochs was set to 30.

\subsubsection{Data Augmentation}
The primary (``with\_aug'') augmentation pipeline applied to the
training set consists of:
\begin{itemize}
  \item Random resized crop to $224 \times 224$ (scale 0.8--1.0)
  \item Horizontal flip ($p=0.5$)
  \item Random rotation ($\pm 10^{\circ}$, $p=0.3$)
  \item Colour jitter (brightness $\pm 0.2$, contrast $\pm 0.2$,
    saturation $\pm 0.1$)
  \item Random affine (translate $\pm 5\%$, shear $\pm 5^{\circ}$)
\end{itemize}
Validation and test images were only resized to $224 \times 224$ and
normalised using ImageNet statistics
($\mu = [0.485, 0.456, 0.406]$, $\sigma = [0.229, 0.224, 0.225]$).

\subsubsection{Implementation Details}
All experiments were run on a Tesla V100-PCIE 16\,GB GPU using
PyTorch 2.8.0, CUDA 12.8, and the Timm library for pretrained
backbones~\cite{rw2019timm}. Batch size was 8 for the
benchmark run and ablation experiments. A global random seed of 42 was
fixed for all random number generators (Python, NumPy, PyTorch, CUDA)
to ensure reproducibility.

% ----------------------------------------------------------------
\subsection{Evaluation Metrics}
\label{subsec:metrics}

Because the dataset is class-imbalanced, we report a comprehensive set
of metrics computed on the validation fold at each cross-validation
iteration:

\begin{itemize}
  \item \textbf{Accuracy:} fraction of correctly classified samples.
  \item \textbf{Balanced Accuracy:} average per-class recall, mitigating
    the effect of class imbalance.
  \item \textbf{Precision / Recall / F1 (pink-eye):} computed specifically
    for the minority class (label~1), which is the clinically relevant
    detection target.
  \item \textbf{ROC-AUC:} area under the receiver operating characteristic
    curve.
\end{itemize}

The primary metric guiding model selection and ablation comparisons is
\emph{F1-score on the pink-eye class} (F1\_pinkeye), as it captures the
balance between false negatives (missed cases) and false positives
(unnecessary interventions).

\subsection{Ablation Experiments}
\label{subsec:ablation}

To isolate the contribution of each augmentation component, four separate
experimental configurations were run:

\begin{enumerate}
  \item \textbf{Baseline (with\_aug):} full augmentation pipeline
    (Section~\ref{subsec:training}).
  \item \textbf{No-colour augmentation:} horizontal flip, rotation
    ($\pm 10^{\circ}$), and mild Gaussian noise ($\sigma \approx 0.01$,
    $p = 0.1$); no colour jitter.
  \item \textbf{Geometric-only (flip + rotation):} horizontal flip and
    rotation only; Gaussian noise removed.
  \item \textbf{Minority-only augmentation:} geometric augmentation
    (flip + rotation) applied exclusively to pink-eye samples; healthy
    samples receive only resize + normalise.
\end{enumerate}

Each configuration was evaluated with all models under the identical
5-fold protocol described above.

\subsection{Explainability Analysis}
\label{subsec:gradcam_results}

Grad-CAM maps were computed for EfficientNet-B0 (Fold~3) and ResNet18
across all folds. For healthy eyes, saliency was broadly distributed
across the clear corneal and scleral regions. For pink-eye samples, the
models consistently activated on the conjunctival and peripheral corneal
areas, regions where hyperaemia and discharge are clinically apparent.
This alignment between model attention and known clinical features
supports the diagnostic validity of the learned representations.

\subsection{Discussion}
\label{subsec:discussion}

\subsubsection{Why the Strong CNN+Transformer Performs Best}
Under full augmentation, the Strong CNN+Transformer achieves the highest
accuracy (95.94\,\%) and F1\_pinkeye (90.51\,\%) among the four
architectures. Several factors contribute to this:

\begin{enumerate}
  \item \textbf{CLS-token aggregation.} The model learns a dedicated
    global representation rather than relying on mean pooling, enabling
    more focused classification signals.
  \item \textbf{Learnable positional embeddings.} Explicit position
    encoding preserves spatial structure within the eye image, aiding
    recognition of anatomically meaningful patterns.
  \item \textbf{Complementary representations.} The CNN backbone captures
    fine-grained local texture cues (e.g., corneal haze, discharge
    streaks) while the Transformer encoder models long-range spatial
    correlations.
  \item \textbf{Deeper MLP head.} The LayerNorm--Linear--GELU--Dropout--
    Linear sequence provides greater discriminative capacity for
    separating subtle healthy vs.\ diseased appearances.
\end{enumerate}

\subsubsection{Architecture--Augmentation Interactions}
The ablation studies reveal that the optimal augmentation strategy is
architecture-dependent. Colour jitter benefits deeper and hybrid
architectures (EfficientNet-B0, both hybrid models) but slightly hurts
ResNet18. Gaussian noise is regularising for shallow CNNs but harmful
for the stronger transformer hybrid. These findings suggest that future
work should systematically tune augmentation policies per architecture,
potentially using automated augmentation search strategies such as
AutoAugment~\cite{cubuk2019autoaugment} or RandAugment~\cite{cubuk2020randaugment}.

\subsubsection{Limitations and Future Work}
The primary limitation is dataset size: 394 labelled eye crops represent
a modest training set for deep learning. To address this, we have designed
a Denoising Diffusion Probabilistic Model (DDPM)~\cite{ho2020ddpm}
pipeline (Stage~2.5) that generates synthetic eye images conditioned on
the disease class label. A conditional UNet with class embeddings is
trained on the real crops; the trained model can then generate additional
pink-eye samples to rebalance the dataset. Integration of synthetic
augmentation into the classification pipeline is reserved for future work.
Additionally, extending the evaluation to multi-class grading (mild /
moderate / severe IBK) and testing on cattle from diverse geographic
regions and breeds would strengthen clinical applicability.
